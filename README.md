## The entry

`main.ts` writes a single line (103 characters) to `entry.txt`: the excuse a
robot vacuum gives for missing a spot — first person, in the vacuum's own
voice, with a concrete scene (the dust under the couch) and a last-line
reversal (it joined the dust's union).

## Run

```sh
MAKEFUN_OUTPUT_DIR=/tmp/robot-vacuum-out npx tsx main.ts
```

The program writes `entry.txt` into the output directory.
